Particle Size Distribution (PSD) Plotter

Semi-log sieve gradation curves with D10, D30 and D60 interpolation, uniformity coefficient Cu and curvature coefficient Cc.

Upload a CSV file containing sieve analysis data to generate gradation envelopes.

  • CSV must contain a Sieve OR Diameter (in mm) column. Standard sieves (e.g., "No. 4", "3/4"") will automatically map to their diameters.
  • Subsequent columns represent material samples (e.g., 'Sample A').
  • Values can be single percentages (e.g., 100) or ranges (e.g., 70-100).
